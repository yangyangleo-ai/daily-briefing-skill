# 定时运行与按需运行

本项目由两个部分组成：宿主 AI 按 Skill 研究与整理；本地脚本校验并导出。脚本本身没有联网采集、模型 API 客户端或常驻调度进程。

先完成一次按需闭环：配置主题 → 公开来源研究 → 结构化阅读稿 → 校验导出 → 打开阅读档 → 下一次增量补读。

如果你使用的宿主提供自动化/定时任务，可在该产品中明确配置时间、时区、运行环境、来源权限和输出位置。例如任务内容可以是：

> 使用 daily-briefing，读取我的 profile 和上一期归档。从上次截止继续到本次实际运行时间，优先原始来源，保留待核项，生成离线阅读档。没有新证据就如实说明，不补造消息。

这段文字只是任务示例，不会创建日程。实际启用后至少验证一次真实触发、权限与输出；记录开始/完成时间和失败原因。不要仅凭“已保存任务”宣称每天准时运行或无人值守验收通过。

需要考虑电脑是否在线、宿主是否仍运行、来源是否可访问、账号是否有效、AI 产品用量与费用以及写入是否冲突。云端宿主不会自动读到本机文件；本地任务也不保证在关机后运行。

没有宿主调度时继续按需更新即可。使用系统任务定期运行导出器，只能导出已经准备好的 JSON，不会自动完成研究成稿。
